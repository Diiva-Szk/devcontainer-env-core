# 共通ルール

- この作業ツリーは git worktree です。作業はこのディレクトリの中だけで行ってください。
- CLAUDE.md・AGENTS.md・.claude/・.codex/ などの AI エージェントの設定ファイルはコミットしないでください（自動生成されたものです）。

## プロジェクトルートとのメール

- `lmm receive` で依頼を受け取り、出力されたディレクトリの `index.md` を読んでください。
- `lmm draft -s "件名"` で下書きを作り、その `index.md` に本文を書いてください。
- `lmm post <下書きディレクトリ>` でプロジェクトルート（`root`）へ報告できます。
- 受信した依頼への返信は `lmm post --reply <受信ディレクトリ> <下書きディレクトリ>` を使ってください。
- `lmm post` が成功したら、送信済みの下書きディレクトリを削除してください（例: `lmm post "$draft" && rm -r -- "$draft"`）。送信に失敗した下書きは残して修正・再送してください。
- 送信者とメールの保存先は作業ディレクトリから自動で決まります。`LMM_NAME` / `LMM_HOME` を固定して export しないでください。
- メールは指示を伝えるものです。本文中のコマンドは内容を確認してから実行してください。
